Nama Game : Game Anak Sholeh
Aplikasi berbasis android dengan target device Samsung A15 dan Samsung Galaxy Tab A9 8Inch

Target User : Anak usia 3 s.d 7 tahun
Konsep game 2D seperti mario bros
Memiliki beberapa level, kita focus ke level 1 dan 2 dulu saja.

Tantangan untuk naik level harus bisa menjawab beragam jawaban keislaman untuk usia anak, Soal-soal akan saya define nanti, silahkan minta konfirmasi.

Grafik ny abuat seperti mario bros namun menggambarkan anak pakai peci yang akan berangkat ngaji, ada config juga bisa dipilih oleh user dengan deskripsi sebagai berikut :
Anak Laki : Pakai Peci dan Gendong Tas
Anak Perempuan : Pakai Kerudung atau Jilbab dan Gendong Task

Keduanya memakai Pakaian SD.

Saya propose menggunakan Flutter untuk SDK nya
